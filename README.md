# Odomètre

Application web de carnet d'entretien automobile (PWA). Tous droits réservés.

- Aucune donnée personnelle n'est collectée ni envoyée : le carnet reste dans le navigateur de l'utilisateur (IndexedDB).
- Seul appel réseau : la vérification de la clé de licence auprès de l'API de licences de Gumroad (clé et identifiant du produit uniquement).
- Aucune police, aucun script ni aucun suivi tiers.
- Démo avec données d'exemple : ajouter `?demo=1` à l'adresse.
